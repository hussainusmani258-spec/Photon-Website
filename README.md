# Photon Portfolio Layout

A clean, responsive, and modern photography portfolio layout featuring a dark aesthetic, custom navbar with dropdown gallery links, social media integration, and visual overlay cards. Built using semantic HTML5, clean CSS3, and Font Awesome icons.

📌 Features

* Clean UI: Dark-themed portfolio design optimized for photographers and visual artists.
* Interactive Navigation: Multi-link header featuring a smooth CSS hover dropdown menu for sub-galleries.
* Font Awesome Icons: Social media branding vectors (Instagram, Facebook, Twitter, YouTube) in the header navigation.
* Flexbox Alignment: Centered layout structures and responsive card containers built with CSS flexbox.
* Human-Coded Style: Straightforward, readable HTML/CSS structure without unnecessary code complexity.

🛠️ Tech Stack

* HTML5
* CSS3
* Font Awesome v6
